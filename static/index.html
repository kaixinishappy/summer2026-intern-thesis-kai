What the agentic passages actually say (deploying vs. exploring vs. naming it a risk)

The agentic-mention count (Data Collection tab) treats every "agentic" mention alike. But reading the passages, an LLM (classify_filings.py) separates three very different things a filing can be doing with the same word: deploying agentic AI in its own products, exploring it, or naming it as a risk / competitive threat. This is the one read the raw count structurally cannot give — and it sharpens Part 3: the big banks' mentions are almost entirely risk disclosures, not deployment. The passages below show the clearest signals (deploying / risk); the table's counts cover all of them, and exploratory / unclear ones are one click away.

Macro-confound control (fintech vs. growth benchmarks, not just banks)

The obvious objection to "fintech rolled over ~2021" is that every unprofitable growth stock sold off in 2022's rate-hike cycle — so this may say nothing fintech-specific. This checks it: the fintech basket's strength relative to QQQ (broad Nasdaq-100 growth) and ARKK (speculative disruptive growth). If fintech underperforms even these, the decline is fintech-specific, not just the growth-stock tide going out.

Robustness agent (a tool-using LLM red-teams the headline breaks)

The stability score is a deterministic grid sweep. This is its qualitative counterpart: a Gemini agent with one tool — probe(w1_weight, pelt_penalty, momentum_window), which recomputes the index and turning points — decides for itself which parameter settings to test, then judges whether each headline break is robust, fragile, or parameter-dependent. It can only probe within the same bounds the sidebar sliders expose, and is capped at a few probes so one run stays cheap. Watch it choose its probes below.
